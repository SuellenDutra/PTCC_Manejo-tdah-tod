# Plataforma de Manejo Comportamental Integrado (TDAH e TOD)

> **Projeto de Trabalho de Conclusão de Curso (PTCC)** > Uma solução tecnológica voltada para o suporte pedagógico, registro ágil de ocorrências e integração na comunicação entre escola e família para o acompanhamento de alunos neurodivergentes.

---

## 📌 Sobre o Projeto

Este projeto propõe uma aplicação web responsiva projetada para mitigar os ruídos de comunicação entre o ambiente letivo e o doméstico no contexto do **Transtorno do Déficit de Atenção com Hiperatividade (TDAH)** e do **Transtorno Opositivo Desafiador (TOD)**. 

A plataforma substitui o modelo tradicional de "registro passivo" e punitivo por uma abordagem de **manejo proativo**. Através de uma interface limpa e de baixa carga cognitiva, os educadores conseguem documentar crises de forma ágil e receber, em tempo real, estratégias de intervenção baseadas em evidências científicas.

---

## 👥 Atores e Perfis de Acesso

* **Educador:** Usuário ativo no ambiente escolar. Responsável por estruturar turmas, monitorar o painel geral de alunos, registrar ocorrências via *chips* de seleção rápida e aplicar as sugestões de manejo sugeridas pelo sistema.
* **Familiar:** Usuário focado no consumo transparente de dados. Responsável por acompanhar a linha do tempo (*timeline*) diária da criança, consultar históricos e emitir relatórios consolidados para suporte clínico.

---

## 🛠️ Funcionalidades Mapeadas (Casos de Uso)

* **UC01 – Estruturar Turmas:** Organização e vínculo de alunos às suas respectivas salas virtuais.
* **UC02 – Exibir Painel Geral:** *Dashboard* visual do educador com o estado atualizado da turma.
* **UC03 – Registrar Ocorrências:** Documentação rápida de crises sem a necessidade de digitação de textos extensos.
* **UC04 – Visualizar Sugestões de Manejo:** Geração automática de *cards* com estratégias práticas de intervenção imediatas `<<include>>`.
* **UC05 – Consultar Histórico:** Acesso centralizado a eventos comportamentais passados para ambos os perfis.
* **UC06 – Acompanhar Linha do Tempo:** *Feed* cronológico e intuitivo para o monitoramento familiar.
* **UC07 – Emitir Relatórios:** Compilação de dados exportáveis em PDF para apoio pedagógico e clínico.
* **UC08 – Autenticar no Sistema:** Controle de acesso seguro segregado por perfil de usuário (LGPD).
* **UC09 – Cadastrar Usuário:** Fluxo de criação de novas contas na plataforma.
